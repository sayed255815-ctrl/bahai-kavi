# بهائی‌کاوی (Bahai-Kavi) — Next.js

## اجرای محلی
1) Node.js (LTS) را نصب کن
2) داخل پوشه پروژه:
```bash
npm install
npm run dev
```
سپس در مرورگر:
http://localhost:3000

## دیپلوی روی Vercel (https://vercel.com/)
روش ساده:
1) یک حساب در Vercel بساز
2) یک ریپو در GitHub بساز و این پروژه را push کن
3) در Vercel → New Project → همان Repo را Import کن
4) Deploy

Build/Run Commands (پیش‌فرض):
- Install: npm install
- Build: npm run build
- Start: npm run start
